# v0.10.0 — Order-email folder baseline (keep your history)

**Linking an IMAP connection never processes old mail**
- When order tracking is linked to an IMAP connection, re-linked, switched to another connection, or the connection's folder/search changes, every message already in the folder is recorded as seen (Message-ID and a sender/subject/date key) without being processed. Only mail that arrives afterwards is acted on. Logged as "Baselined N existing messages in folder …"
- Your Kroger label can and should keep its full order history
- If the folder can't be read, nothing is processed until it can: a Repairs issue explains, and it retries every 5 minutes
- The baseline and seen list persist, so restarts never reprocess anything (HA's IMAP integration re-announces the newest message at each start; it's ignored)

**Fix:** "seen" checks no longer use the IMAP event's `uid`. HA's IMAP integration reports SEARCH sequence numbers there, which shift when mail leaves the folder, so a new email could have been mistaken for an old one. Dedupe is now by Message-ID and content only. The seen list keeps up to 2,000 entries (was 200).

**Upgrade note:** if you're on v0.9.0, update before linking an IMAP connection to a folder that already has order mail.
