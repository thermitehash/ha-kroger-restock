# v0.6.0 — Stock checks, printing, order tracking, ESPHome scanner

Everything since v0.1.0: phases 2–5, plus order tracking.

**Stock and order days**
- Waiting items are re-checked every few hours (default 3 h). When one is back in stock it's pushed to the cart, or held until your order-day window
- Give-up repair for items waiting too long (keep waiting or remove; never automatic)
- Notifications, `readd_item` and `check_stock` actions, Check stock now button, Held sensor

**Printing**
- ESC/POS receipt printer over the network (58/80 mm)
- Two-column letter PDF, saved to /media/kroger_restock, optional IPP printing
- `print_list` action, Print receipt / Print PDF buttons

**Kroger order tracking (new)**
- Kroger order sensor (placed, shopping, ready, out for delivery, completed, cancelled), read from Kroger's order emails through HA's IMAP integration
- Pickup window, item count and total; `kroger_restock_order_update` event; optional re-add of shorted items
- Tested with real Kroger pickup emails (confirmation, ready, final receipt)

**Scanning**
- QR codes, Data Matrix and other non-product codes on packaging are now ignored

**Extras**
- "At the store" blueprint, example automations, iPhone Shortcut guide
- ESPHome wall scanner (ESP32 + GM65/GM861) with buzzer/LED feedback

**Upgrade notes**
- Stored data upgrades automatically
- New options pages: Printing, Order tracking

Not affiliated with Kroger.
