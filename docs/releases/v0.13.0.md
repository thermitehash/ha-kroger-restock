# v0.13.0: Restock scanner card

**New dashboard card: Restock scanner** (included with the integration, no separate install or resource; search "Restock scanner" in Add card)
- **Scan button:**
  - In the Home Assistant app: the app's own barcode scanner. Scan item after item; each result shows in the scanner.
  - In a browser over https (e.g. Home Assistant Cloud): a full-screen camera. Safari, iOS and Firefox use a barcode reader shipped with the integration (about 1 MB, loaded only when the camera opens, never from the internet).
- **Text field:** a barcode, an item name, or a pasted product link.
- **Recent items:** the last items added to the list, newest first, with quantity, status, aisle and how long ago.
  - − / + change the quantity. At 1 the − button asks before removing. Lowering an item already in the Kroger cart shows "Remove N from the Kroger app cart".
  - Undo +1 on items you scanned again.
  - Fix opens the to-do list for items that need review or weren't found.
- **Options:** title, rows, scanner (auto / app / camera / off), text field, buttons, and an optional button that runs an iPhone Shortcut. All set in the visual editor.

**New sensor: Recently scanned.** Its state is the newest item; the `items` attribute lists the last 25 items added to the list (kept out of history). It works in Markdown cards too.

**New scan source:** `card`.

**Tested:** unit tests for the card, plus a real-browser check in Chromium (rendering in light, dark and phone layouts; a generated barcode read through the camera and the built-in reader). The app's own scanner and the camera inside the Home Assistant app are not yet tested on a phone.
