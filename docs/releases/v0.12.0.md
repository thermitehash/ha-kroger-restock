# v0.12.0: Set quantity (and undo a duplicate scan)

**New action `kroger_restock.set_quantity`** (`item_id` or `name`, `quantity`)
- `quantity: 0` removes the item from the list
- Not pushed yet (waiting, held, needs review…): just changes the number
- Already in the Kroger cart, raising: pushes only the extra units
- Already in the Kroger cart, lowering: Kroger's API can't remove from the cart, so the Home Assistant record is lowered and you get a warning, "Remove N from the Kroger app cart: …", in the response and as a notification
- Items waiting on a cart check (Repairs) must be confirmed first
- `name` must match exactly one active item

**To-do list:** each item shows `×N` when the quantity is above 1. Editing it follows the same rules: lowering a pushed item now warns instead of being ignored, `×1` goes back to one, `×0` removes the item. Leaving `×N` off keeps the quantity.

**Undo +1:** with Notify on every scan on, the "↺ Already on list" push has an Undo +1 button (Undo +N for larger quantities). A second tap, or a tap after the quantity changed, does nothing.

**Docs:** verified live on v0.11.0:
- the Share Sheet Shortcut from the Kroger iOS app (Get URLs from Input → `scan_upc` with `url`);
- Perform Action returning the response to Shortcuts (notification title `result`, body `name · aisle`);
- a Kroger store-brand barcode;
- a QR code being ignored.
