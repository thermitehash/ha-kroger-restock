# v0.17.3: Notice items added in the Kroger app

Kroger's emails never list items, and Kroger's API has no order history, so Home Assistant can't see which items were added in the Kroger app. It can see how many.

**Untracked items:**
- When the order confirmation arrives, Kroger Restock compares the order's item count with the units it pushed. For example, 47 in the order and 35 pushed means **12 untracked**.
- New sensor **Untracked items in last order** shows that number.
- When the order is picked up or delivered, the new event `kroger_restock_untracked_items` fires once, and you're told: *"12 items in your Kroger order weren't added through Home Assistant. Scan them when you unload to add them to the pantry."*
- `recent_received` now includes `untracked_count` and `untracked_orders`.
- Pushed items are linked to the order number, so `kroger_restock_received` carries it even when you check an item off by hand.

**Privacy:**
- Email subjects, which contain first names, are no longer stored or logged, and old ones are removed from storage.
- The order event's `subject` field is replaced by `email`, the kind of email (placed / ready / completed).
- Kroger Restock opens the order folder read-only.

**Also:**
- The order sensor shows subtotal, savings and tax.
- The dated pickup window is kept when the ready email only says "Today …".

**Note:** Kroger's "number of items" is assumed to count units (2 × milk = 2). This hasn't yet been checked against a real order that has quantities above one.
