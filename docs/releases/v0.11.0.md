# v0.11.0: Add by link, per-scan notifications, pre-order cart check

**Add by product link or ID**
- `scan_upc` takes `product_id` (13-digit Kroger product ID, looked up directly with no barcode guessing) or `url`; `add_item` takes `url`
- Works with kroger.com and Kroger-banner product links (`/p/<name>/<id>`), including query strings, fragments and links embedded in shared text
- A link to another site, or to a Kroger page that isn't a product page, returns `result: ignored`
- README: a two-step Share Sheet Shortcut (`{"url": "[Shortcut Input]", "source": "shortcut"}`)

**Notify on every scan** (Settings, default off)
- One short push per scan, add or shared link: ✓ In cart · ⏳ Waiting on stock · ? Unknown code · ↺ Already on list · • Needs review · ⊘ Ignored
- All use one notification tag, so rapid scans replace each other
- Useful if your Shortcut's Perform Action doesn't return response data (not yet tested)

**Pre-order cart check** (new "Cart check" options page, default off)
- Hours before each order day (default 6), or weekly at a set day/time when no order days are set
- Lists what Home Assistant believes is in your Kroger cart (name × quantity), unconfirmed pushes, and how many items are waiting on stock
- Buttons: **Matches** · **Something's missing from HA** (type names; each is recorded with `already_in_cart: true`) · **Open list**
- New action `kroger_restock.cart_check` sends it now and returns the list
- Never changes the Kroger cart

**Docs:** verified live: the order-email folder baseline against real Gmail, the out-of-stock path, and the named-area aisle rule ("Produce"). PDF printing over IPP is configured but not yet tested.
