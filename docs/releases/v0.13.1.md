# v0.13.1: Scanner card shows up in the card picker

**Fix:** the Restock scanner card didn't appear in **Add card**. The integration now adds the card to your dashboard resources on startup, the same way other card-shipping integrations do. It updates the resource's version after every update, so browsers don't keep a stale copy, and removes duplicates. YAML-mode dashboards still get the card loaded on every page, and the README shows how to add it as a resource.

- The card is now listed as **Kroger Restock scanner**, so searching "Kroger" finds it.
- If the card's files are missing (for example a partial download), Home Assistant now logs a warning instead of skipping the card silently.
- Removing the integration's last entry removes the dashboard resource.

**After updating:** restart Home Assistant, then reload the dashboard. In the Home Assistant app: Settings → Companion app → Debugging → Reset frontend cache.
